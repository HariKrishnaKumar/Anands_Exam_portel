5. DETAILED FILE SPECIFICATIONS

--------------------------------------------------------------------------------
5.1  src/php/config/n8n.php
--------------------------------------------------------------------------------

  Purpose:    Load N8N configuration from environment variables
  Pattern:    Follows same style as config/mail.php

  Contents:
    - Read N8N_WEBHOOK_URL from $_ENV (falls back to .env)
    - Read N8N_TIMEOUT (default: 30 seconds)
    - Read N8N_ENABLED (default: true) — kill switch
    - Define constants: N8N_WEBHOOK_URL, N8N_TIMEOUT, N8N_ENABLED

--------------------------------------------------------------------------------
5.2  src/php/includes/ai_helper.php
--------------------------------------------------------------------------------

  Purpose:    Core AI integration logic — security layer between student
              and N8N

  Functions:

    ai_sanitize_input($message)
      - Strip HTML tags
      - Remove special characters
      - Trim whitespace
      - Max length: 2000 characters
      - Returns clean string

    ai_check_allowed($message)
      - Block patterns: "what is the answer", "give me answer",
        "show answer", "exam answer", "test answer", "quiz answer",
        "send me paper", "leaked", "cheat"
      - Returns true if allowed, false if blocked
      - Logs blocked attempts

    ai_call_n8n($studentId, $studentName, $message, $sessionId)
      - POST to N8N_WEBHOOK_URL
      - Body: { student_id, student_name, message, session_id, timestamp }
      - Uses curl with timeout
      - Returns decoded JSON response
      - Handles errors gracefully (timeout, 500, network failure)

    ai_build_student_context($pdo, $studentId)
      - (Phase 2) Queries student's own data: name, course, batch,
        recent test scores, upcoming tests
      - Returns array for N8N to use
      - READ-ONLY queries only

--------------------------------------------------------------------------------
5.3  src/php/api/ai_chat.php
--------------------------------------------------------------------------------

  Purpose:    AJAX endpoint for chat messages

  Method:     POST only (reject GET)
  Auth:       Requires active student session (session.php include)
  Content-Type: application/json

  Request body:
    { "message": "student's question" }

  Response (success):
    {
      "status": "ok",
      "reply": "AI response text",
      "blocked": false
    }

  Response (blocked):
    {
      "status": "blocked",
      "reply": "I can help with exam instructions and study tips, but I cannot provide answers to tests or exams.",
      "blocked": true
    }

  Response (error):
    {
      "status": "error",
      "reply": "Sorry, I'm having trouble. Please try again later."
    }

  Flow:
    1. Verify session (student is logged in)
    2. Rate limit check (max 20 messages per minute per session)
    3. Sanitize input
    4. Check if message is allowed (answer-restriction filter)
    5. If blocked → return blocked response, log attempt
    6. If allowed → call N8N webhook with student context
    7. Return N8N response to student

--------------------------------------------------------------------------------
5.4  src/php/api/ai_student_data.php (Phase 2)
--------------------------------------------------------------------------------

  Purpose:    Read-only student data API for N8N to call

  Method:     POST only
  Auth:       Requires N8N API key in header (X-N8N-API-Key)
              OR called from same-origin only

  Returns:
    - Student's own test results (marks, grades)
    - Upcoming tests
    - Performance summary (avg score, trend)
    - Portal navigation links

  Restrictions:
    - Can ONLY access data for the student_id passed in request
    - Cannot access other students' data
    - Cannot modify any data
    - Read-only SELECT queries

  UI Components:

  API Call:
    - POST to /api/ai_chat.php
    - Headers: Content-Type: application/json
    - Body: { message: "text" }
    - Timeout: 30 seconds
    - On error: show "Connection lost" message

  Dark Mode:

    - Uses CSS variables (--bg-primary, --text-primary, etc.)
    - Watches for theme class changes on <body>

================================================================================

  ┌──────────────────────────────────┬──────────────────────────────────┐
  │ Rule                             │ Where Enforced                   │
  ├──────────────────────────────────┼──────────────────────────────────┤
  │ Student must be logged in        │ ai_chat.php — session check      │
  │ Rate limit: 20 msgs/min         │ ai_chat.php — session counter    │
  │ Input max 2000 chars            │ ai_sanitize_input()              │
  │ Block answer requests           │ ai_check_allowed() — regex       │
  │ N8N never touches MySQL         │ Architecture — PHP is gateway    │
  │ Chatbot cannot modify data      │ ai_student_data.php — SELECT     │
  │ Student sees only own data      │ ai_student_data.php — WHERE id   │
  │ XSS prevention                  │ ai_sanitize_input() + h()        │
  │ SQL injection prevention        │ Prepared statements everywhere   │
  │ No Laravel/new framework        │ Explicit constraint              │
  └──────────────────────────────────┴──────────────────────────────────┘

  Blocked patterns (in ai_check_allowed()):
    - "what is the answer"
    - "give me answer"
    - "show answer"
    - "exam answer"
    - "test answer"
    - "quiz answer"
    - "send me paper"
    - "leaked"
    - "cheat"
    - Custom patterns can be added to a blocklist array
