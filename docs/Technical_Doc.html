1. Project Overview

1.1 What Is This?

The Yajurvedh Exam Portal is a full-stack web application built by Yajurvedh (an IIT/IIM alumni venture) for managing online examinations for educational institutions.

Core Capabilities:

  • Multi-tenant college management (BGS Institute, BIM, etc.)
  • Automated MCQ grading with instant scoring
  • Manual grading for coding and explanation questions
  • Real-time exam monitoring with tab-switch detection
  • PCI (Performance Competency Index) scoring algorithm
  • Analytics dashboards with charts and reports
  • Guest/QR-based test access
  • Email OTP verification for student registration

1.2 User Roles

  • Primary brand: Yajurvedh (exam portal login/signup)
  • Institution brand: BGS Group Of Institutions (custom login at /bgs.php)
  • Logos: assets/img/yajurvedh-logo.png and assets/img/bgs-logo.png

4.3 PCI Scoring Formula

Performance Competency Index (PCI) = (MCQ% x 0.40) + (Coding% x 0.30) + (Explanation% x 0.30)

Bands: Excellent (>=80), Good (>=60), Average (>=40), Needs Improvement (<40)

5. PHP Backend Architecture

5.1 Request Lifecycle

Request -> env.php (load .env) -> db.php (define getDB()) -> session.php (start session + CSRF)
  -> auth.php (check role) -> page controller -> include header -> render HTML -> response

5.2 Config Layer (src/php/config/)

env.php - Environment Variable Loader

  • No Composer dependency (custom implementation)
  • Priority: real getenv() > > default
  • Parses .env at project root (supports comments, quoted values)
  • Path: dirname(__DIR__, 3) . '/.env' (3 levels up from config/)

db.php - Database Configuration

  • Singleton PDO connection via getDB()
  • Auto-detects PHP built-in server vs Apache for BASE_URL
  • Global error/exception handlers feed into admin notification bell
  • Sets timezone to Asia/Kolkata (UTC+5:30)

mail.php - SMTP Configuration

  • Two drivers: 'smtp' (direct fsockopen) or 'mail' (PHP mail())
  • All credentials from .env - never hardcoded
  • Dev mode: logs OTP to file instead of sending

5.3 Core Includes (src/php/includes/)

session.php

  • startSession() - starts session, regenerates ID every 30 min (anti-fixation)
  • CSRF token generation and validation
  • csrfField() - renders hidden input for forms
  • requireCsrf() - kills request with 403 if CSRF invalid

auth.php - Authentication Engine

  • adminLogin() - single query, bcrypt verify, session write + release
  • studentLogin() - UNION query across students + unverified_students
  • studentRegister() - inserts into unverified_students, sends OTP email
  • generateStudentOtp() - 6-digit OTP, bcrypt hash, 10-min expiry
  • verifyStudentOtp() - moves record from unverified to students (transaction)
  • guestLogin() - token-based, session role = 'guest'
  • Brute-force protection: 5 attempts / 15-minute window per email
  • Critical: session_write_close() called BEFORE redirect to prevent session lock bottleneck under 200+ concurrent logins

helpers.php

  • h() - HTML entity encoding (XSS prevention)
  • redirect() - portable redirect (strips XAMPP prefix)
  • flash() / flashMessage() - one-time flash messages with SVG icons
  • generateToken() - cryptographically secure random tokens
  • pythonApiRequest() - HTTP client for Python Flask (with retries + backoff)
  • recalculatePciForSubmission() - PCI with Python-first, PHP-fallback strategy
  • getStudentTests() - eligible tests for a student (batch-based)
  • notifyAdmin() - creates notification bell entries
  • PHP 8 polyfills for PHP 7.x (str_starts_with, str_contains)

mailer.php - Custom SMTP Client

  • Built with fsockopen() - zero external dependencies
  • Full SMTP conversation: EHLO -> STARTTLS -> AUTH LOGIN -> MAIL FROM -> RCPT TO -> DATA -> QUIT
  • Gmail App Password authentication
  • sendOtpEmail() - HTML email template with branded styling

6. Authentication and Security

6.1 Student Registration Flow

signup.php -> studentRegister()
  1. Validate college/course/batch hierarchy
  2. Check duplicate email in both tables
  3. Insert into unverified_students (bcrypt password, cost=10)
  4. generateStudentOtp() -> 6-digit OTP, bcrypt hash (cost=8), 10-min TTL
  5. Send OTP email via SMTP
  6. Redirect to verify-otp.php

verify-otp.php -> verifyStudentOtp()
  1. Fetch from unverified_students
  2. Check OTP expiry
  3. password_verify() against stored hash
  4. BEGIN TRANSACTION
  5. INSERT INTO students (move record)
  6. DELETE FROM unverified_students
  7. COMMIT
  8. Redirect to login

6.2 Login Flow

login.php -> adminLogin() or studentLogin()
  1. isBruteForceLocked() - check failed_login_log (5 attempts / 15 min)
  2. Query (admin: single table, student: UNION across 2 tables)
  3. password_verify() (bcrypt, cost=10)
  4. session_regenerate_id(true)
  5. Set session vars: role, id, email, name
  6. session_write_close() - release lock BEFORE redirect
  7. Redirect to dashboard

6.3 Security Features

FeatureImplementation
CSRF Protection32-byte random token, per-session, validated on all POST requests
XSS Preventionh() function wraps all output in htmlspecialchars()
SQL InjectionPDO prepared statements everywhere (no raw queries)
Password Hashingbcrypt cost=10 for passwords, cost=8 for OTPs
Session Fixationsession_regenerate_id(true) on login + every 30 min
Brute Force5 attempts per 15-min window, IP logged
OTP Security6-digit, bcrypt-hashed, 10-min expiry, single-use

9. SMTP Email System

9.1 How It Works

mailer.php -> sendOtpEmail()
  1. Build HTML email with OTP code
  2. Call sendMail() -> checks MAIL_DEV_MODE
  3. If dev mode: log to file, return
  4. If MAIL_DRIVER = 'smtp':
     a. fsockopen(smtp.gmail.com, 587)
     b. EHLO -> STARTTLS -> stream_socket_enable_crypto()
     c. EHLO (post-TLS) -> AUTH LOGIN
     d. base64_encode(username) -> base64_encode(password)
     e. MAIL FROM -> RCPT TO -> DATA
     f. Send headers + HTML body
     g. QUIT
  5. Return success/failure
Important: Gmail requires a 16-character App Password (not your regular password). Generate at: https://myaccount.google.com/apppasswords. 2FA must be enabled first.
